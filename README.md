# MucusPlugNavigator

MucusPlugNavigator is a 3D Slicer extension for lung CT mucus plug review.

## Purpose

This extension helps users manage mucus plug segments inside lung-room segments.

## Main features

- Create mucus plug segments linked to lung-room segments
- Select and jump to mucus plugs
- Edit plugs using Segment Editor tools
- Count total mucus plugs
- Calculate mucus score based on rooms that contain at least one mucus plug
